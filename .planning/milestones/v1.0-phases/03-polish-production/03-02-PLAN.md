**3. Nav.astro -- add Escape key handler and aria-expanded (per D-07, addresses Pitfall 5):**

On the `<button id="menu-toggle">` element, add `aria-expanded="false"`:
```html
<button id="menu-toggle" class="md:hidden" aria-label="Toggle menu" aria-expanded="false">
```

In the `<script>` section, update the openMenu and closeMenu functions to toggle aria-expanded:

```js
function openMenu() {
  menu?.classList.remove("translate-x-full");
  menu?.classList.add("translate-x-0");
  toggle?.setAttribute("aria-expanded", "true");
  document.body.style.overflow = "hidden";
}

function closeMenu() {
  menu?.classList.remove("translate-x-0");
  menu?.classList.add("translate-x-full");
  toggle?.setAttribute("aria-expanded", "false");
  document.body.style.overflow = "";
}
```

Add Escape key handler after the existing event listeners:
```js
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape" && menu?.classList.contains("translate-x-0")) {
    closeMenu();
    toggle?.focus();
  }
});
```

Do NOT change the intersection observer logic, the links array, or the HTML structure beyond adding aria-expanded.
