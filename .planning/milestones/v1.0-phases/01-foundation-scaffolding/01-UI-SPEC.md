## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tag pill vertical padding |
| sm | 8px | Compact element spacing, tag pill horizontal padding, gap between inline items |
| md | 16px | Default element spacing, paragraph margin-top |
| lg | 24px | Section internal padding, horizontal page padding (mobile) |
| xl | 32px | Layout gaps between major elements |
| 2xl | 48px | Major section breaks |
| 3xl | 96px | Page-level vertical padding (py-24 in Tailwind = 96px) |

Exceptions: 96px (3xl) -- Page-level vertical padding. Generous whitespace per linear.app/vercel.com design energy. Multiple of 4, grid-safe. Not in the standard spacing set (4, 8, 16, 24, 32, 48, 64) but justified by the dark-theme aesthetic requiring more breathing room between major page sections.

**Source:** Default 8-point scale. RESEARCH.md code examples use px-6 (24px), py-24 (96px), mt-4 (16px), mt-16 (64px), gap-2 (8px) which align with this scale. The 3xl token is 96px (not 64px) to match the actual py-24 usage in the proof-of-concept page.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 16px | 400 (regular) | 1.5 | text-base font-normal |
| Label / Small | 14px | 400 (regular) | 1.5 | text-sm font-normal |
| Heading 2 | 24px | 600 (semibold) | 1.2 | text-2xl font-semibold |
| Display / Heading 1 | 36px | 700 (bold) | 1.1 | text-4xl font-bold |

Font stack (declared in @theme): `"Geist Variable", "Inter", system-ui, sans-serif`

Weights used: 400 (regular) and 600 (semibold) as primary pair. 700 (bold) is a single-element exception reserved exclusively for the display heading ("Russell Moore" at text-4xl). This third weight is justified because the display heading must visually separate from section headings (semibold 600) -- at 36px, the weight difference between 600 and 700 is perceptible and establishes clear hierarchy. No other element uses 700.

**Source:** CONTEXT.md D-10, D-11. Sizes derived from RESEARCH.md code examples (text-4xl, text-2xl, text-lg, text-sm). Formalized to 4 roles with 2 primary weights + 1 declared exception.

## Color

| Role | Value | CSS Token | Usage |
|------|-------|-----------|-------|
| Dominant (60%) | #0a0a0f | --color-background | Page background, all surfaces |
| Foreground | #f5f5f5 | --color-foreground | Primary text, headings |
| Secondary (30%) | #a1a1aa | --color-muted | Secondary text, descriptions, metadata |
| Accent (10%) | #7c3aed | --color-accent | Tech stack tag background (at 20% opacity), accent highlights |
| Accent hover | #8b5cf6 | --color-accent-hover | Hover state for accent elements |
| Card surface | rgba(255,255,255,0.05) | bg-white/5 | Card backgrounds (subtle elevation) |
| Card border | rgba(255,255,255,0.10) | border-white/10 | Card borders (subtle separation) |
| Destructive | not needed | -- | No destructive actions in Phase 1 |

Accent reserved for:
- Tech stack tag pill backgrounds (at 20% opacity: bg-accent/20)
- Tech stack tag pill text color (text-accent)
- Future: CTA buttons, links, active nav items (Phase 2)

**Source:** CONTEXT.md D-09, RESEARCH.md Pattern 3 (global.css @theme tokens), RESEARCH.md code examples (bg-white/5, border-white/10, bg-accent/20, text-accent).

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Page load | Dark background renders immediately (inline style). No white flash. No font layout shift. |
| Scroll | Native browser scroll. No custom scroll behavior in Phase 1. |
| Hover | None in Phase 1 (no interactive elements beyond browser defaults). |
| Responsive | max-w-4xl centered container with px-6 horizontal padding. Content reflows naturally. |

## Dark Theme Implementation
