Create `src/components/timeline/TimelineBar.astro` with this exact interface:

```typescript
interface Milestone {
  year: number | string;
  yearNum: number;            // Numeric year for positioning (e.g., 2007)
  label: string;
  detail: string;
  position: "above" | "below";
}

interface Props {
  startYear: number;
  endYear: number;
  milestones: Milestone[];
}
```

**Structure:**

1. **Outer scroll container** (mobile horizontal scroll per D-02, research Pattern 3):
```html
<div class="relative overflow-x-auto scroll-smooth [-webkit-overflow-scrolling:touch] [scroll-snap-type:x_mandatory]">
```

2. **Inner timeline area** with `min-w-[600px] relative py-16 px-8 mx-auto`:

3. **Horizontal line**: `div` with `absolute left-8 right-8 top-1/2 h-0.5 bg-white/15`

4. **Year markers along the line**: Generate year labels for each year from startYear to endYear. Each year marker positioned absolutely using `left: ${((year - startYear) / (endYear - startYear)) * 100}%` within a relatively-positioned container that matches the line's left/right padding. Year labels: `text-[10px] text-muted/60` positioned below the line at `top-1/2 mt-4`. Show tick marks as small `h-2 w-px bg-white/10` vertical lines at each year.

5. **Milestone nodes**: For each milestone, render a `<MilestoneNode>` positioned absolutely using percentage-based left offset: `left: ${((m.yearNum - startYear) / (endYear - startYear)) * 100}%`. Wrap each in a div with `absolute top-1/2 -translate-x-1/2 -translate-y-1/2`. Pass `edge="left"` to the first milestone (index 0) and `edge="right"` to the last milestone.

6. **Mobile scroll indicator** (shown only on small screens):
```html
<p class="mt-2 text-center text-xs text-muted md:hidden">Swipe to explore timeline &rarr;</p>
```

**Milestone clustering (per pitfall 2 from research):** For milestones sharing the same yearNum, automatically alternate position between "above" and "below" regardless of what was passed. This prevents overlapping labels. Implementation: in the frontmatter script, group milestones by yearNum. If a yearNum has 2+ milestones, force alternating positions.

**Key implementation details:**
- Import MilestoneNode from `./MilestoneNode.astro`
- All positioning uses percentage-based calc, NOT fixed pixels
- The inner container min-width of 600px forces horizontal scroll on mobile while maintaining proportional positioning
- Year markers should NOT be shown for every year if the span is large (>8 years). In that case, show every 2nd year to reduce clutter. Use: `const yearStep = (endYear - startYear) > 8 ? 2 : 1;`
