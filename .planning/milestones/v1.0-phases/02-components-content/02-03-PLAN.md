Astro frontmatter block (between the component's triple-dash delimiters):

```typescript
import { getCollection } from "astro:content";
import Card from "../Card.astro";
import Badge from "../Badge.astro";
import SectionHeader from "../SectionHeader.astro";

const allProjects = await getCollection("projects");
const sortedProjects = allProjects.sort((a, b) => a.data.order - b.data.order);
const featured = sortedProjects.filter((p) => p.data.featured);
const other = sortedProjects.filter((p) => !p.data.featured);
```

Template structure (D-09: featured hero cards + compact list):
```html
<section id="projects" class="py-24">
  <div class="mx-auto max-w-4xl px-6">
    <SectionHeader title="Projects" subtitle="What I'm building" />

    <!-- Featured projects: larger cards (PROJ-03) -->
    <div class="grid gap-6 md:grid-cols-2">
      {featured.map((project) => (
        <Card variant="featured">
          <div class="flex items-start justify-between">
            <h3 class="text-xl font-semibold text-foreground">{project.data.title}</h3>
            <Badge variant="status">{project.data.status}</Badge>
          </div>
          <p class="mt-3 text-muted">{project.data.description}</p>
          <div class="mt-4 flex flex-wrap gap-2">
            {project.data.stack.map((tech) => (
              <Badge variant="tech">{tech}</Badge>
            ))}
          </div>
          {project.data.url && (
            <a href={project.data.url} target="_blank" rel="noopener noreferrer" class="mt-4 inline-flex items-center gap-1 text-sm text-accent hover:text-accent-hover transition-colors">
              Visit project
            </a>
          )}
        </Card>
      ))}
    </div>

    <!-- Non-featured projects: compact list below (D-09) -->
    {other.length > 0 && (
      <div class="mt-8 space-y-4">
        {other.map((project) => (
          <Card>
            <div class="flex items-center justify-between">
              <div>
                <h3 class="font-semibold text-foreground">{project.data.title}</h3>
                <p class="mt-1 text-sm text-muted">{project.data.description}</p>
              </div>
              <Badge variant="status">{project.data.status}</Badge>
            </div>
            <div class="mt-3 flex flex-wrap gap-2">
              {project.data.stack.map((tech) => (
                <Badge variant="tech">{tech}</Badge>
              ))}
            </div>
          </Card>
        ))}
      </div>
    )}
  </div>
</section>
```

Key decisions reflected:
- D-09: Featured projects get `variant="featured"` cards (larger, more detail). Non-featured in compact list below
- PROJ-01: Uses getCollection("projects") sorted by order field

- PROJ-03: Featured cards use Card variant="featured" for visual distinction
- Pitfall 7: Explicit sort by order field, not relying on filesystem order
