```css
.hero-gradient {
  position: absolute;
  inset: 0;
  overflow: hidden;
  z-index: 0;
}

.hero-gradient::before {
  content: "";
  position: absolute;
  inset: -50%;
  background:
    radial-gradient(circle at 30% 40%, rgba(124, 58, 237, 0.15) 0%, transparent 50%),
    radial-gradient(circle at 70% 60%, rgba(59, 130, 246, 0.08) 0%, transparent 50%),
    radial-gradient(circle at 50% 50%, rgba(124, 58, 237, 0.05) 0%, transparent 70%);
  animation: meshMove 20s ease-in-out infinite alternate;
  will-change: transform;
}

@keyframes meshMove {
  0% { transform: translate(0, 0) scale(1); }
  33% { transform: translate(2%, -3%) scale(1.02); }
  66% { transform: translate(-2%, 2%) scale(0.98); }
  100% { transform: translate(1%, -1%) scale(1.01); }
}
```

- D-04: min-h-[65vh] gives 60-70vh range
- HERO-03: Animate transform only (not background-position) for GPU performance
