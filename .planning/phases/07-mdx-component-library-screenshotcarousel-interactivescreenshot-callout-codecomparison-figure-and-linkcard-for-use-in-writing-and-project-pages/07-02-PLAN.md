**ScreenshotCarousel.astro (per D-01, D-02, D-03, D-04, D-21, D-22, D-23):**

Props interface:
```typescript
interface Props {
  images: Array<{ src: string; alt?: string; caption?: string }>;
}
```

**HTML structure:**
1. Wrapper `<div class="screenshot-carousel my-6 not-prose">` with unique data attribute `data-carousel`
2. Scroll container: `<div class="carousel-track flex gap-4 overflow-x-auto scroll-snap-x-mandatory pb-4" style="scroll-snap-type: x mandatory; -webkit-overflow-scrolling: touch;">` (use inline style for scroll-snap since Tailwind v4 utility may not exist)
3. Each image: `<div class="carousel-slide flex-shrink-0 scroll-snap-start" style="scroll-snap-align: start; width: min(100%, 600px);">` containing:
   - `<button class="carousel-img-btn cursor-zoom-in w-full" data-full-src={img.src} data-full-alt={img.alt || img.caption || ""}>` wrapping the img for lightbox trigger
   - `<img src={img.src} alt={img.alt || img.caption || ""} class="w-full rounded-lg border border-white/10" loading="lazy" />`
   - If caption: `<p class="mt-2 text-center text-sm text-muted">{img.caption}</p>` (per D-03)
4. Arrow buttons (left/right): `<button class="carousel-arrow carousel-prev ..." aria-label="Previous">` and next. Style: absolute positioned, `bg-white/10 hover:bg-white/20 rounded-full p-2`, centered vertically. Use left/right chevron characters or inline SVG.
5. Shared lightbox dialog (singleton -- per research pitfall 1): `<dialog class="carousel-lightbox" style="background: transparent; border: none; max-width: 90vw; max-height: 90vh;">` containing:
   - `<img class="carousel-lightbox-img max-w-full max-h-[85vh] rounded-lg" />`
   - `<button class="carousel-lightbox-close absolute top-4 right-4 text-white text-2xl bg-black/50 rounded-full w-10 h-10 flex items-center justify-center" aria-label="Close">&times;</button>`
   - Style `dialog::backdrop { background: rgba(0,0,0,0.85); }` in a `<style>` block

**Script block (vanilla JS per D-21):**
- Use `document.querySelectorAll("[data-carousel]")` to handle multiple instances per page (pitfall 1)
- For each carousel:
  - Arrow click: `container.scrollBy({ left: direction * scrollAmount, behavior: "smooth" })` where scrollAmount = first child offsetWidth + 16 (gap)
  - Image click: find/create singleton dialog, set img src/alt, call `dialog.showModal()`
- Lightbox close: click close button calls `dialog.close()`, click on dialog backdrop also closes (check `e.target === dialog`)
- Dialog Escape key close is native behavior -- no JS needed

**InteractiveScreenshot.astro (per D-05, D-06, D-07, D-08, D-21, D-22, D-23):**

Props interface:
```typescript
interface Hotspot {
  x: number;  // percentage 0-100
  y: number;  // percentage 0-100
  label: string;
  detail: string;
}
interface Props {
  src: string;
  alt?: string;
  hotspots: Hotspot[];
}
```

**HTML structure:**
1. Wrapper: `<div class="interactive-screenshot relative my-6 inline-block not-prose" data-interactive-screenshot>`
2. Base image: `<img src={src} alt={alt || ""} class="w-full rounded-lg border border-white/10" loading="lazy" />`
3. Hotspot overlay: For each hotspot, render:
   ```html
   <button class="hotspot-dot absolute" style={`left: ${hotspot.x}%; top: ${hotspot.y}%;`}
     data-hotspot-label={hotspot.label} data-hotspot-detail={hotspot.detail}
     aria-label={hotspot.label} tabindex="0">
     <span class="hotspot-number">{index + 1}</span>
   </button>
   ```
4. Tooltip container (shared, appended to body by JS for fixed positioning): NOT in template -- created dynamically by JS like TimelineBar pattern

**Hotspot dot styling (in `<style>` block):**
- `.hotspot-dot`: `transform: translate(-50%, -50%); width: 28px; height: 28px; border-radius: 50%; background: rgba(167, 139, 250, 0.9); display: flex; align-items: center; justify-content: center; cursor: pointer; border: 2px solid rgba(255,255,255,0.3);`
- `.hotspot-number`: `font-size: 12px; font-weight: 600; color: white;`
- Pulse animation per research recommendation:
  ```css
  @keyframes pulse-ring {
    0% { transform: translate(-50%, -50%) scale(1); opacity: 0.8; }
    100% { transform: translate(-50%, -50%) scale(2.5); opacity: 0; }
  }
  .hotspot-dot::before {
    content: ""; position: absolute; inset: -4px; border-radius: 50%;
    background: rgba(167, 139, 250, 0.4);
    animation: pulse-ring 2s ease-out infinite;
  }
  ```

**Script block (replicating TimelineBar tooltip pattern per D-06):**
- Detect touch: `const isTouch = "ontouchstart" in window;`
- Create tooltip div if not exists: fixed position, `z-index: 9999`, dark bg `(bg #1a1a2e)`, rounded, padding, shadow, max-width 250px
- Tooltip content: bold label + detail text
- For each `[data-interactive-screenshot]`:
  - Query all `.hotspot-dot` children
  - Desktop (per D-06): `mouseenter` shows tooltip positioned via `getBoundingClientRect()` with viewport clamping, `mouseleave` hides
  - Mobile (per D-07): `click/touchstart` toggles tooltip. Track `activeNode` -- if same node clicked again, hide. If different node, reposition.
  - Keyboard: `focus` shows, `blur` hides
- Positioning: Use `getBoundingClientRect()` on the dot, place tooltip above by default, flip below if not enough space. Clamp horizontally to viewport edges with 8px padding.
- Click outside (on mobile): hide tooltip when clicking anywhere that isn't a hotspot
