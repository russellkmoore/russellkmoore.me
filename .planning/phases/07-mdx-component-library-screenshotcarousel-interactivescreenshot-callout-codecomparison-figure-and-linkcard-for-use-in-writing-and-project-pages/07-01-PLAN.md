**Callout.astro (per D-09, D-10, D-11, D-21, D-22, D-23):**
- Props interface: `{ type?: "info" | "warning" | "tip" | "note" }`
- Default type: "info"
- Import `Icon` from `astro-icon/components`
- Use a lookup object (NOT dynamic class construction -- Tailwind v4 won't detect dynamic strings) for variant styles:
  - info: `border-blue-500 bg-blue-500/10` icon `lucide:info`
  - warning: `border-amber-500 bg-amber-500/10` icon `lucide:alert-triangle`
  - tip: `border-emerald-500 bg-emerald-500/10` icon `lucide:lightbulb`
  - note: `border-zinc-500 bg-zinc-500/10` icon `lucide:pencil`
- Layout: `border-l-4` left accent, flex row with icon on left (size-5, shrink-0, matching border color), content area with `<slot />` on right
- Wrapper div: `rounded-lg p-4 my-6` with variant bg/border classes
- Text inside slot inherits prose styling (no explicit text color needed)
- Zero JS -- pure HTML/CSS component

**Figure.astro (per D-15, D-16, D-17, D-21, D-22, D-23):**
- Props interface: `{ src: string; alt?: string; caption?: string; width?: string; bordered?: boolean; shadow?: boolean }`
- Render `<figure>` element with `my-6` margin
- `<img>` with: `src`, `alt` (fallback to caption then empty string), `loading="lazy"`, `class:list` with conditional `border border-white/10 rounded-lg` if bordered, `shadow-lg shadow-black/20` if shadow
- If `width` prop provided, apply as inline `style={width ? \`max-width: ${width}\` : undefined}` on the figure
- If `caption`, render `<figcaption class="mt-2 text-center text-sm text-muted">{caption}</figcaption>`
- Zero JS -- pure HTML component
